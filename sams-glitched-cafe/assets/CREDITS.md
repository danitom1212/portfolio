# Asset credits

All backgrounds and the character sprite are illustrated art (not
photographs), chosen so the whole scene shares one visual language.
Each was resized and heavily color-graded / glitch-processed offline to
match the game's neon palette — the files in this folder are the
processed output, not the originals.

## Backgrounds

| File | Used for | Source |
|---|---|---|
| `bg-cafe.jpg`, `bg-cafe-dim.jpg`, `bg-cafe-glitch.jpg` | café interior scenes | "Spiral Atlas VN House Backgrounds" (dining room) by Spiral Atlas, via https://opengameart.org/content/visual-novel-house-backgrounds — CC BY 3.0 |
| `bg-street.jpg` | rainy night street scene | Original artwork, generated procedurally for this project (no third-party source) |
| `bg-void.jpg` | climax / liminal-space scene | "Hellish/Underworld Background for Visual Novel" by cowardlion, via https://opengameart.org/content/hellishunderworld-background-for-visual-novel — CC0 |

Attribution for the café background: "Spiral Atlas VN House Backgrounds"
by Spiral Atlas, licensed under [CC BY 3.0](https://creativecommons.org/licenses/by/3.0/).

## Character sprite

**"Codel Visual Novel Sprite"** by **LisadiKaprio**, via

License: [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/) —

## The antagonist ("Static")

Rendered as an original abstract SVG (in `faces.js`), not third-party
art — deliberately not illustrated as a human character, since it is not
meant to read as one.
